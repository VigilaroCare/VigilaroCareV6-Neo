## Como usar

1. Abra o arquivo da área que quer revisar.
2. Edite o texto que vem **depois** de cada linha `**[ID]**`. Não mexa na linha do ID — é ela que diz onde o texto volta no código.
3. Pode reescrever, encurtar, aprofundar ou marcar com um comentário seu. Devolva o arquivo e eu reaplico.

Só o **pt-BR** está aqui. Português de Portugal, inglês e espanhol são atualizados a partir da sua versão final — não precisa revisar os três.

`_mapa-de-ids.json` é o índice que liga cada ID ao lugar exato no código. Não precisa abrir.
