## Próximos passos — Estratégia de uso no app

- Baixar imagens do Drive via MCP (base64)
- Salvar em `assets/images/prevencao/` no projeto
- Usar `require('@/assets/images/prevencao/protetor-de-tomada.jpg')` nos data files
- ✅ Funciona offline · ✅ Performance · ✅ Sem rate-limit do Drive

### Opção B: CDN próprio (ImgBB/Cloudinary)

- Subir em CDN
- URLs públicas nos data files
- ✅ APK menor · ⚠️ Depende de internet
